---

## Reporting a Vulnerability

We take the security of Free Proxy Checker seriously. If you discover a security vulnerability, please follow these guidelines:

1. **Do not create a public GitHub issue** for undisclosed security vulnerabilities.
2. Please contact the project maintainers directly or use GitHub Private Vulnerability Reporting if enabled.
3. Provide details including:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if available)

We will review reports promptly and publish patches accordingly.

---

## 🛑 Important Security Notice Regarding Free Proxies

- **Public Proxies are Untrusted**: Publicly available proxies collected by this tool are operated by unknown third parties. They can intercept, inspect, or modify unencrypted traffic.
- **Never Route Confidential Data**: Never transmit credentials, passwords, session tokens, or private personal data through free public proxies.
